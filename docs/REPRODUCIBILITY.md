# 复现范围

## 本次发布内容

本项目将已运行研究中的扩散计算、U-Net 适配、噪声条件卷积和局部轨迹目标整理为 `nctd` 包，移除了对原工作区目录和历史脚本的导入。训练、数据加载、采样入口是为本次发布编写的便携实现。

基础实现使用宽度 32 的三层 U-Net，通道倍数为 1、2、2，每层一个残差块，不使用注意力和 dropout。零初始化卷积修正分布在解码器的四处 16×16 卷积。条件系数由噪声方差确定，不是额外学习的路由网络。

原始扩散数值文件与三个第三方 U-Net 源文件保持一致。模型初始化、前向和参数梯度、优化器分组以及跨度 4/8 的辅助损失已与原实现进行 CPU 对照。来源文件的 SHA256 见 `source_provenance.json`。浮点运行中，TorchScript 预热和算子实现可能引入微小舍入差异。

## 保留的设置

- 64 个训练时间点，终点信号系数平方为 `1e-5`，同步余弦日程，标准 v 预测。
- 基础参数学习率 `2e-4`，卷积增量参数学习率 `1e-4`，Adam，EMA 衰减 `0.999`。
- 默认训练批次 64，轨迹辅助样本最多取其中 16 张，默认辅助权重 `0.1`。
- 学生两次局部 DDIM 更新，冻结教师四次更新，以局部角度差的正弦归一化终点残差。学生中间状态保留梯度。
- 正式评价使用 31 步 DDIM。采样时不引入局部轨迹教师。

## 与历史实验的区别

归档结果使用旧实验程序、固定的 60000 步父检查点、预先保存的随机数与评价参考。发布包没有重新运行完整的 GPU 对照，也没有将历史结果改成便携程序的成绩。

便携训练入口使用独立随机数生成器和完整检查点。它支持同一便携环境中的断点恢复，但随机流、数据驻留方式、日志与检查点布局不承诺和旧实验程序完全一致。因此，从头运行可能得到不同数值，不能把结果文件作为本次代码运行的自动验收阈值。

包内未附数据集、历史训练权重、Inception 权重、参考特征或原始 GPU 调度日志。需要重做 KID 评价时，应额外准备 TF-FID 兼容的 2048 维 Inception 特征，固定显示量化、参考图像、生成噪声和 KID 子集设置。仅换用另一个名字相同的 Inception 网络并不能保证指标可比。

## 比较规则

新的对照应先固定数据划分、父检查点、种子、训练预算、采样步数和指标定义。局部跨度的对照还应固定辅助起点范围，区分区间长度与起点分布的影响。保留各个训练种子及生成噪声组的结果，注明模型选择过程。

结果中的低频与局部块距离衡量像素统计，不等同于生成图像的语义正确性或人眼清晰度。局部两步学生目标也不代表两步完整生成或训练加速。已经保存的局限和未改善条件见 `EXPERIMENTS.md`。
